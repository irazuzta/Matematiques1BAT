# Nombres reals

Apunts del tema **Nombres reals** de Matemàtiques de 1r de Batxillerat.

Aquest tema recorda i amplia els conjunts numèrics treballats en cursos anteriors i introdueix les eines bàsiques per treballar amb nombres reals: l'ordre a la recta real, els intervals, el valor absolut, les potències, les arrels i els logaritmes.

- [Intervals i valor absolut](intervals-valor-absolut.md) — intervals, valor absolut, distàncies i inequacions lineals.
- [Aproximacions i errors](aproximacions-errors.md) — truncament, arrodoniment, error absolut i error relatiu.
- [Potències](potencies.md) — definició, propietats i notació científica.
- [Arrels i radicals](arrels.md) — definició, relació amb les potències i propietats.
- [Logaritmes](logaritmes.md) — definició, propietats i aplicacions.
- [Nota històrica](nota-historica.md) — com han evolucionat els nombres reals al llarg de la història.
