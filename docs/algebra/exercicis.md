## 1. Polinomis

**1.** Per a cada polinomi, indica'n el grau, el coeficient principal i el terme independent:

| | |
|:--|:--|
| **a)** $3x^4-2x^3+x-7$ | **b)** $-5x^3+4x^2-1$ |
| **c)** $x^5-3x^2$ | **d)** $8$ |

**2.** Avalua cada polinomi en el valor indicat i digues si es tracta d'una arrel:

- **a)** $p(x)=x^3-4x+3$ en $x=1$
- **b)** $p(x)=x^3-4x+3$ en $x=2$
- **c)** $q(x)=2x^2-5x-3$ en $x=3$
- **d)** $q(x)=2x^2-5x-3$ en $x=-1$

**3.** Donats $p(x)=2x^3-x^2+4x-1$ i $q(x)=-x^3+3x^2-2x+5$, calcula $p(x)+q(x)$ i $p(x)-q(x)$.

**4.** Desenvolupa:

| | |
|:--|:--|
| **a)** $(2x-1)(x^2+3x-2)$ | **b)** $(x+3)^2$ |
| **c)** $(x-2)(x+2)$ |  |

**5.** Divideix i indica el quocient i el residu:

- **a)** $(2x^3-3x^2+4x-5):(x^2-1)$
- **b)** $(x^4-1):(x^2+1)$

**6.** Divideix per Ruffini, indicant el quocient i el residu:

- **a)** $(x^3-6x^2+11x-6):(x-2)$
- **b)** $(2x^3+x^2-5x+2):(x+2)$
- **c)** $(x^4-5x^2+4):(x-1)$

**7.** Sense fer la divisió completa, aplica el teorema del residu i el teorema del factor:

- **a)** Calcula el residu de dividir $P(x)=2x^3-5x^2+3x+4$ entre $x-2$.
- **b)** Determina el valor de $k$ perquè $x-2$ sigui divisor de $P(x)=x^3+kx^2-5x+6$.

**8.** Desenvolupa aplicant la identitat notable corresponent:

| | |
|:--|:--|
| **a)** $(x+6)^2$ | **b)** $(x-3)^2$ |
| **c)** $(2x+1)^2$ | **d)** $(x+5)(x-5)$ |

**9.** Desenvolupa (vigila els coeficients i els exponents en elevar al quadrat):

| | |
|:--|:--|
| **a)** $(2x^2-3y)^2$ | **b)** $(3x-2y^2)^2$ |
| **c)** $(x^3+2y)^2$ | **d)** $(4x^2-y^3)(4x^2+y^3)$ |

**10.** Desenvolupa, parant atenció als signes:

- **a)** $(-x-4y)^2$
- **b)** $(-2x+3)^2$. Compara el resultat amb el de $(2x-3)^2$: per què donen el mateix?
- **c)** $(-3x-1)(3x-1)$ *(indicació: treu primer signe menys factor comú d'un dels dos factors)*
- **d)** Digues quina identitat notable s'amaga darrere de $4x^2-12x+9$ i escriu-la com un quadrat.

- **a)** $x^3-3x^2+4x-2$

**16.** Factoritza completament cada polinomi (no hi ha cap indicació de quin cas és cadascun):

## 3. Fraccions algebraiques

**21.** Calcula el MCD i el MCM mònic de cada parell de polinomis:

- **a)** $A(x)=x^2-9$, $B(x)=x^2-x-6$
- **b)** $A(x)=x^3-x$, $B(x)=x^2+2x+1$

**22.** Simplifica i indica els valors que queden exclosos del domini original:

| | |
|:--|:--|
| **a)** $\dfrac{x^2-1}{x^2+2x+1}$ | **b)** $\dfrac{x^2-4}{x^2-5x+6}$ |
| **c)** $\dfrac{x^2+3x}{x^2-9}$ | **d)** $\dfrac{x^3-x}{x^2-x}$ |

**23.** Per a cada apartat, indica si la igualtat és certa per a tots els valors admesos pels dos membres. Escriu també els valors exclosos:

| | |
|:--|:--|
| **a)** $\dfrac{x+2}{x^2+4}=\dfrac{1}{x+2}$ | **b)** $\dfrac{x-3}{x^2-9}=\dfrac{1}{x+3}$ |
| **c)** $\dfrac{x^2+2x}{2x}=x+2$ | **d)** $\dfrac{x^2-2x}{x-2}=x$ |

**24.** Opera, simplifica i indica els valors exclosos del domini original:

- **a)** $\dfrac{1}{x-1}+\dfrac{2}{x+1}$
- **b)** $\dfrac{x}{x^2-4}-\dfrac{1}{x+2}$
- **c)** $\dfrac{3}{x}+\dfrac{x}{x-3}$

**25.** Opera, simplifica i indica els valors exclosos del domini original:

- **a)** $\dfrac{x+3}{x-1}\cdot\dfrac{x^2-1}{(x+3)^2}$
- **b)** $\dfrac{x^2-4}{x+1}:\dfrac{x-2}{x+1}$

**26.** Opera, simplifica i indica els valors exclosos del domini original: $\dfrac{1}{x}+\dfrac{1}{x+1}-\dfrac{2}{x^2+x}$.

**27.** Demostra les identitats següents i indica per a quins valors de $x$ són vàlides:

- **a)** $\dfrac{1}{x-1}-\dfrac{1}{x+1}=\dfrac{2}{x^2-1}$
- **b)** $\dfrac{x}{x+1}+\dfrac{1}{x+1}=1$

## 4. Problemes en context

**28.** *(aplicat)* Un rectangle té una àrea de $x^3-x^2-4x+4$ i un dels costats fa $x-1$. Troba, factoritzant, l'expressió de l'altre costat i determina per a quins valors de $x$ totes dues longituds són positives.

**29.** *(aplicat)* Un dipòsit prismàtic té un volum $V(x)=x^3+2x^2-5x-6$. Si dues de les seves dimensions són $x+1$ i $x-2$, troba la tercera i determina per a quins valors de $x$ les tres dimensions són positives.

**30.** *(aplicat)* Simplifica $\dfrac{x^2-9}{x-3}$, indica el valor exclòs del domini original i avalua el resultat per a $x=5$.

**31.** Factoritza i simplifica $\dfrac{x^3-4x}{x^2-x-2}$, i indica els valors exclosos del domini original.

**32.** Factoritza, simplifica i indica els valors de $x$ pels quals l'expressió original no està definida: $\dfrac{x^3-2x^2-3x}{x^2-9}$.

**33.** *(aplicat)* D'una làmina de cartró rectangular de $20\,\text{cm}\times12\,\text{cm}$ es retalla un quadrat de costat $x$ a cada cantonada i es doblega per formar una caixa sense tapa. Perquè la caixa es pugui construir, cal que $0<x<6$.

- **a)** Expressa el volum $V(x)$ de la caixa com un polinomi.
- **b)** Calcula el volum per a $x=2\,\text{cm}$.

**34.** *(aplicat)* Una empresa estima que, en fabricar $x$ centenars d'unitats d'un producte, els ingressos (en milers d'€) són $I(x)=x^3-x^2-2x+8$ i els costos són $C(x)=x^2+3x+2$.

- **a)** Calcula el benefici $B(x)=I(x)-C(x)$.
- **b)** Factoritza $B(x)$ i troba els punts d'equilibri (valors de $x>0$ pels quals el benefici és nul).
- **c)** Avalua $B(2)$ i interpreta el signe del resultat.

**35.** El nombre d'usuaris (en milers) d'una aplicació mòbil, $t$ mesos després del llançament, es modelitza per $N(t)=t^3-5t^2+2t+8$.

- **a)** Calcula $N(5)$.
- **b)** Factoritza $N(t)$ i indica per a quins valors de $t\geq0$ el model prediu zero usuaris.

## 5. Exercicis inspirats en les PAU

> Aquests exercicis estan inspirats en proves PAU (Selectivitat) dels darrers anys (2022–2026). És important tenir en compte que, als exàmens originals, aquests càlculs formen part d'un problema més ampli —normalment de càlcul, matrius o geometria, propis de 2n de Batxillerat— i aquí n'aïllem només el fragment o procediment algebraic (factorització, equacions, fraccions algebraiques...) que té relació directa amb aquest tema.

**36.** *(PAU 2024)* Factoritza completament $x^3-4x^2+4x$ i troba'n totes les arrels.

**37.** *(PAU 2026)* Factoritza completament $2x^3-8x$ i troba'n totes les arrels.

**38.** *(PAU 2022)* Factoritza el denominador i indica el domini de $f(x)=\dfrac{9}{x^2+x-2}$.

**39.** *(PAU 2023)* Resol per factorització l'equació $4x^2-10x-6=0$.

**40.** *(PAU 2024)* Factoritza completament i resol $x^3-7x^2+6x=0$.

**41.** *(PAU 2022, guiat)* Comprova, factoritzant, que $x^3-3a^2x+2a^3=(x-a)^2(x+2a)$.

**42.** *(PAU 2025)* Resol:

- **a)** $x^3+1=0$ (dona només la solució real)
- **b)** si $a^3=8$, troba el valor real de $a$

**43.** *(PAU 2025)* Factoritza completament $4p^3-5p^4$ i troba'n totes les arrels.

**44.** *(PAU 2025)* Donada $f(x)=\dfrac{x^2-2x}{x-1}$:

- **a)** Factoritza el numerador i troba els punts de tall amb l'eix $X$.
- **b)** Comprova si existeix cap valor de $x$ que compleixi $x^2-2x+2=(x-1)^2$.

**45.** *(PAU 2024)* Resol l'equació $3x^2+2x+2=x^2+2x+4$ (passa-ho tot a un costat i factoritza).

**46.** *(PAU 2024)* Resol per factorització $x^2-2x-15=0$.

**47.** *(PAU 2025)* Troba els valors del paràmetre que anul·len cada expressió, factoritzant-la:

- **a)** $p^2-1$
- **b)** $\lambda^2+3\lambda-10$

**48.** *(PAU 2026)* Troba els valors de $m$ que anul·len $m^2-4m+3$, factoritzant-lo.
